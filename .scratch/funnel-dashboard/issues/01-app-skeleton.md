# 01 — Каркас приложения: конфиг, атомарный стор, HTTP-сервер

**What to build:** `npm start` поднимает сервер на `PORT` (по умолчанию 3000), отдаёт статику из `public/`, отвечает на `/health` и `/ready`. Аналитический снимок хранится в JSON-файле, который переживает падение процесса в момент записи.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

Читать до старта: `CONTEXT.md`, `reference/CODE_REUSE_MAP.md`.
Референс к адаптации: `reference/altech/src/config.js`, `src/storage/jsonStore.js`, `server.original.js` (только каркас: `json()`, `serveStatic`, `readJsonBody`, `/health`, `/ready`, единый catch).

- [ ] `src/config.js` — чтение окружения с защитой: нечисловое значение числовой переменной логируется и заменяется дефолтом, а не роняет старт. `ROOT_DIR` через `fileURLToPath`. Флаг `configDegraded` при отсутствии ключа Битрикса.
- [ ] `.env.example` со всеми именами переменных и пустыми значениями. Реальных секретов в репозитории нет.
- [ ] `src/storage/jsonStore.js` — форма снимка задана константой `EMPTY_CACHE` и подмешивается при каждом чтении и записи (`{...EMPTY_CACHE, ...data}`), чтобы миграции схемы были бесплатны.
- [ ] Запись атомарна: временный файл в том же каталоге + `rename` поверх целевого. Прерывание записи не портит существующий снимок.
- [ ] Битый JSON уезжает в `*.corrupt` и не затирается следующим сохранением; отсутствие файла (ENOENT) — штатная ситуация, не ошибка.
- [ ] Абсолютный путь к файлу снимка не вкладывается в `ROOT_DIR`.
- [ ] `src/server.js` — маршрутизация без фреймворка, единый конверт ответа `{success, data}` / `{success:false, error:{code, message}}`, `Cache-Control: no-store` на API.
- [ ] Статика защищена от обхода каталога двойной проверкой: нормализация пути + проверка префикса. Белый список MIME.
- [ ] `/health` — liveness, всегда 200, снимок не читает. `/ready` — readiness, 503 при неготовности.
- [ ] Тело запроса ограничено по размеру, поток дочитывается до конца (иначе клиент получает обрыв соединения вместо внятного 413). Битый JSON в теле даёт 400, не 500.
- [ ] `package.json`: `type: module`, `engines.node >= 20`, скрипты `start` / `check` / `test`. **Ноль внешних зависимостей.**
- [ ] `npm run check` проходит.
