# 05 — Трассирующая пуля: Статика первой воронки от снимка до экрана

**What to build:** Открываешь `localhost:3000` — видишь тёмный стеклянный дашборд с воронкой компаний за текущий квартал в режиме Статики. Числа посчитаны из демо-снимка настоящим расчётным модулем и приехали по HTTP. Это первый сквозной срез через все слои; дальше система только расширяется.

**Blocked by:** 01, 02, 03, 04

**Status:** ready-for-agent

Читать до старта: `CONTEXT.md` целиком, спека — разделы `Режим Статики`, `Конверсии`, приложения А2/А3.
Дизайн: `reference/altech/design/GLASS_DASHBOARD_HANDOFF.md` — токены и классы брать дословно; `reference/altech/design/glass-reference.html` — визуальный эталон.
Фронт-референс: `reference/altech/public/app.js` — конверт ответа, race guard, делегирование кликов; `styles.css` — стеклянные панели и воронка.

Объём намеренно узкий: **только Статика, только первая воронка, без фильтров**. Вторая воронка, Динамика, фильтры, конверсии-селекторы, детализация и XLSX — отдельные тикеты, здесь их нет.

- [ ] `calculateDashboard(snapshot, request)` — единственная точка расчёта. Возвращает применённый запрос, свежесть данных, ступени с единицей учёта и количеством, конверсию к предыдущей ступени, предупреждения.
- [ ] Когорта Статики: компании, впервые перешедшие на «Взят в работу» внутри периода.
- [ ] Компания учитывается не более одного раза на каждом этапе — считается размер множества, а не количество событий истории.
- [ ] Пропущенные положительные этапы докрашиваются до фактически достигнутого.
- [ ] Откат компании не стирает достигнутые этапы: используется исторический максимум.
- [ ] Конверсия к предыдущей ступени, округление до 0.1; первая ступень — 100%; нулевой знаменатель даёт 0% без ошибки.
- [ ] `GET /api/dashboard` — параметры режима и периода, ответ в конверте `{success, data}`. Формулы в сервере не дублируются: он только вызывает расчётный модуль.
- [ ] `public/index.html` + `styles.css` — тёмная тема, дизайн-токены и стеклянные панели дословно из handoff-документа, фон-градиент обязателен (иначе `backdrop-filter` нечего размывать). Шрифты Manrope / Unbounded подключены с локальным фолбэком на системные.
- [ ] Воронка сверстана горизонтальными пропорциональными барами: название, полоса, количество, конверсия. Ширина полосы — доля от максимума, с минимальным порогом, чтобы нулевая ступень оставалась видимой.
- [ ] `public/app.js` — состояние в одном объекте, безопасный разбор ответа (не-JSON от прокси даёт внятную ошибку, а не `Unexpected token`), **race guard**: у каждого запроса монотонный номер, ответ устаревшего запроса игнорируется и в успехе, и в ошибке.
- [ ] Различимы три состояния: загрузка, ошибка запроса, пустой результат фильтрации. Пустой результат — не ошибка.
- [ ] Всё, что приходит с сервера, экранируется перед вставкой в разметку.
- [ ] `scripts/check-static-funnel.mjs` — проверки на фикстурах: компания не дублируется на ступени; пропущенный этап докрашен; откат не стёр историю; когорта отбирается по первому входу во «Взят в работу»; сущность вне периода в когорту не попала; нулевой знаменатель не роняет расчёт.
- [ ] `npm run check` и `npm test` проходят.
