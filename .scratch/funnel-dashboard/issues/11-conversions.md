# 11 — Конверсии: главная и выбираемая сквозная

**What to build:** Верхний блок экрана: крупно главная коммерческая конверсия «Взят в работу → Аванс получен», рядом — сквозная конверсия между двумя любыми выбранными этапами и счётчики компаний, потребностей и сделок.

**Blocked by:** 06

**Status:** ready-for-agent

Читать до старта: `CONTEXT.md` (раздел «Конверсии»), спека — раздел `Конверсии` целиком, приложение А3.

Тонкое место — расчёт через точку соединения: смешивать компании и сделки в одной дроби нельзя, поэтому показателей там два.

- [ ] Формула: `сущности конечного этапа / сущности начального этапа × 100%`, точность до одного десятичного знака, целые значения отображаются без дробной части.
- [ ] Главная коммерческая конверсия — от «Взят в работу» до «Аванс получен», выводится крупно.
- [ ] «Передано в производство» показывается как следующая операционная ступень и **не** заменяет главную коммерческую конверсию.
- [ ] Пользователь выбирает любые два этапа для сквозной конверсии; выбор конечного этапа раньше начального не допускается.
- [ ] Оба этапа в первой воронке ⇒ расчёт по уникальным компаниям. Оба во второй ⇒ по уникальным сделкам.
- [ ] **Диапазон пересекает «Потребность выявлена»** ⇒ основной показатель — конверсия потребностей в выбранный нижний этап; дополнительно показывается отношение результата к числу компаний на выбранном верхнем этапе. Оба показателя подписаны так, чтобы было видно, что считается по компаниям, а что по сделкам.
- [ ] Нулевой знаменатель ⇒ `0%` и пояснение об отсутствии исходных сущностей; расчёт не падает и не показывает `NaN` или `Infinity`.
- [ ] Все конверсии приходят из расчётного модуля — интерфейс не вычисляет проценты сам.
- [ ] Счётчики среза (компании / потребности / сделки) согласованы с соответствующими ступенями воронки.
- [ ] `scripts/check-conversions.mjs` — проверки: конверсия внутри первой воронки считается по компаниям; внутри второй — по сделкам; расчёт через стык возвращает основной и дополнительный показатели с верной базой у каждого; нулевой знаменатель даёт 0% без исключения; округление до 0.1 и отображение целых; главная конверсия не подменяется операционной ступенью.
