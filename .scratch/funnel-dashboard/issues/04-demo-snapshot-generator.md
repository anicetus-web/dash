# 04 — Генератор демо-снимка

**What to build:** Детерминированный генератор нормализованного снимка, наполняющий систему правдоподобными данными строительно-производственного B2B. Демо обязано проявлять все правила расчёта — иначе на нём нельзя доказать, что расчёт верен.

**Blocked by:** 02 — Доменная конфигурация двух воронок

**Status:** ready-for-agent

Читать до старта: `CONTEXT.md` (инварианты расчёта), спека — приложение А4.

Форма снимка: компании; сделки со связью на компанию; история стадий обеих воронок; история ответственных; текущая стадия и признак отказа сделки; справочники менеджеров, источников и форматов КЭВ; метаданные последней синхронизации.

- [ ] Генератор детерминирован: фиксированное зерно даёт побайтово тот же снимок. Собственный ГПСЧ, `Math.random()` не используется.
- [ ] Объём достаточен для правдоподобной картины: порядка 300–500 компаний и 400–700 сделок, история за 12+ месяцев, 6–8 менеджеров, 5–7 источников.
- [ ] Названия компаний, источников и объектов — правдоподобный B2B строительства и производства, не «Компания 1», «Тест», «Lorem».
- [ ] Воронка сужается правдоподобно: на каждом этапе отсеивается часть сущностей, к «Передано в производство» доходят единицы. Числа не должны выглядеть синтетически ровными.
- [ ] **Обязательно представлены все краевые случаи**, каждый в количестве, достаточном для проверки:
  - [ ] компании с несколькими потребностями и, соответственно, несколькими сделками;
  - [ ] компании, откатившиеся в первой воронке (история достигнутых этапов должна сохраниться);
  - [ ] активные сделки, откатившиеся во второй воронке (глубина должна обрезаться текущей стадией);
  - [ ] сделки, откатившиеся и снова продвинувшиеся (не должны дублироваться);
  - [ ] проигранные сделки, сохраняющие положительный путь до отказа;
  - [ ] сущности с пропущенными положительными этапами (докрашиваются расчётно);
  - [ ] повторные входы на один этап в пределах периода;
  - [ ] передачи сущности между менеджерами в середине пути;
  - [ ] записи без источника → категория «Источник не указан»;
  - [ ] сделки без формата КЭВ → «Не указано».
- [ ] История стадий и история ответственных согласованы между собой и с текущим состоянием сущности: не бывает события позже «сейчас», отката без предшествующего продвижения, сделки без связанной компании.
- [ ] Даты распределены по всему диапазону так, чтобы любой стандартный период (неделя, месяц, квартал, год) давал непустой результат.
- [ ] `scripts/check-demo.mjs` — проверки целостности: у каждой сделки существует компания; события отсортированы и не в будущем; каждый заявленный краевой случай реально присутствует в снимке (проверять фактическим поиском, а не доверием к генератору); повторный запуск с тем же зерном даёт идентичный результат.
