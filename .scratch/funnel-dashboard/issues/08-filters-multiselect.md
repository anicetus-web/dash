# 08 — Мультивыбор фильтров и справочники

**What to build:** Панель фильтров: база/источник, менеджер, формат КЭВ — каждый с множественным выбором. Фильтры применяются совместно и мгновенно пересчитывают воронку по локальному снимку.

**Blocked by:** 06

**Status:** ready-for-agent

Читать до старта: `CONTEXT.md`, спека — раздел `Фильтры` целиком и приложение А1.
Референс: `reference/altech/src/analytics/dashboard.js` — `matchesFilters`, `buildFilterReference`. **Важно:** в Altech все фильтры одиночные, мультивыбор пишется с нуля; в интерфейсе Altech обычные `select`, их переиспользовать нельзя.

- [ ] Несколько значений одного фильтра объединяются по ИЛИ, разные фильтры — по И.
- [ ] Пустой выбор означает «все значения», а не «ничего».
- [ ] **Фильтр КЭВ применяется только ко второй воронке** (приложение А1). Ступени первой воронки при выбранном КЭВ показывают все компании, прошедшие остальные фильтры, и не обнуляются. Счётчик компаний на стыке показывает компании, породившие отфильтрованные сделки.
- [ ] Пустой формат КЭВ отображается отдельным значением «Не указано» и не теряется при выборе конкретных форматов.
- [ ] Запись без источника попадает в категорию «Источник не указан» и **не** включается при выборе конкретной базы.
- [ ] Дедупликация при мультивыборе: компания по ID компании, сделка по ID сделки — сущность, подходящая под два выбранных значения, считается один раз.
- [ ] `GET /api/reference` отдаёт справочники доступных менеджеров, источников, форматов КЭВ и стадий. «Не указано» всегда последним в списке.
- [ ] Контрол множественного выбора написан свой: выпадающий список с чекбоксами, счётчиком выбранного, кнопкой «сбросить», доступный с клавиатуры (стрелки, Enter, Escape) и с корректными ARIA-атрибутами. Стилистика — стеклянная, из дизайн-токенов.
- [ ] Применённые фильтры возвращаются в ответе и восстанавливаются в интерфейсе из ответа сервера.
- [ ] `scripts/check-filters.mjs` — проверки: ИЛИ внутри фильтра; И между фильтрами; пустой выбор = все; отсутствие дублей при мультивыборе; «Источник не указан» исключается при выборе конкретной базы; «Не указано» в КЭВ сохраняется; **фильтр КЭВ не обнулил первую воронку**; счётчик компаний на стыке согласован с отфильтрованными сделками.
