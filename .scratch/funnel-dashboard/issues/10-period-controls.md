# 10 — Периоды в интерфейсе и «Вся история выбранных баз»

**What to build:** Панель выбора периода: неделя, месяц, квартал, год, произвольный диапазон дат и режим «Вся история выбранных баз». По умолчанию открывается текущий квартал.

**Blocked by:** 05

**Status:** ready-for-agent

Читать до старта: спека — раздел `Периоды`, `Режим Статики` пункт 10, `Режим Динамики` пункт 7.
Референс: `reference/altech/public/app.js` — управление периодами. **Важно:** произвольного диапазона в Altech нет, он пишется с нуля.

- [ ] Пять стандартных типов периода плюс произвольный диапазон, переключаются сегментным контролом.
- [ ] По умолчанию — текущий календарный квартал, без обращения к серверу за дефолтом.
- [ ] Произвольный диапазон: два поля даты, начальная и конечная включаются полностью. Диапазон «конец раньше начала» не отправляется, пользователю показывается внятная причина.
- [ ] Режим «Вся история выбранных баз» доступен **только в Статике**. При переключении в Динамику контрол становится недоступен, а активный режим «Вся история» корректно сбрасывается на период по умолчанию — молча отправлять недопустимый запрос нельзя.
- [ ] Границы периода отображаются подписью, чтобы пользователь видел фактически посчитанный диапазон.
- [ ] Период, обрезанный текущим моментом, не выглядит как ошибка: подпись показывает естественные границы периода, а расчёт — обрезанные.
- [ ] Сервер остаётся источником истины по границам: интерфейс восстанавливает состояние контролов из применённых параметров ответа.
- [ ] Смена периода не создаёт гонку: при быстром переключении применяется ответ последнего запроса (используется race guard из тикета 05).
- [ ] Контролы доступны с клавиатуры, у сегментного переключателя корректные ARIA-атрибуты.
