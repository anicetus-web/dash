# 3ДБИЛД — дашборд воронки продаж

Веб-дашборд сквозной воронки продаж через две воронки Битрикс24 («Компании» и «Сделки»)
с режимами Статики и Динамики. Размещается на платформе «Битрикс24 Вайбкод».

## Начать отсюда

1. [`CONTEXT.md`](CONTEXT.md) — глоссарий домена и инварианты расчёта. **Читать до любой работы с расчётным модулем.**
2. [`.scratch/funnel-dashboard/spec.md`](.scratch/funnel-dashboard/spec.md) — источник истины по объёму работ.
3. [`reference/CODE_REUSE_MAP.md`](reference/CODE_REUSE_MAP.md) — что можно брать из референса Altech, а что нельзя.

## Стек

Node.js ≥ 20, ESM, **ноль внешних зависимостей**. Фронтенд — ванильный JS без шага сборки.
Не добавляй зависимости без явного согласования: отсутствие сборки — осознанное решение
ради надёжного деплоя на Вайбкод.

```bash
npm start      # сервер на http://localhost:3000
npm run check  # синтаксическая проверка всех файлов
npm test       # проверки расчётного модуля и хранилища
```

## Референс Altech

`reference/altech/` — отобранный код рабочего дашборда другого проекта. Это **референс, не заготовка**:
у Altech одна воронка сделок, у нас две воронки с переходом «Компания → Сделка», два режима,
атрибуция менеджеров по истории и особые правила откатов.

Брать оттуда паттерны (атомарный стор, single-flight синк, race guard на фронте, стеклянный дизайн) —
да. Копировать бизнес-формулы и технические ID стадий Altech — нет.

Чего в Altech нет и что пишется с нуля: мультивыбор фильтров, произвольный диапазон дат,
часовой пояс портала, атрибуция менеджера по истории ответственных, переход между двумя воронками.
