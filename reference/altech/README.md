# Отобранный референс Altech

Это не автономное приложение Altech и не стартовый код 3ДБИЛД. Каталог содержит связанные исходники, необходимые для изучения архитектурных, расчётных и интерфейсных решений.

## Что можно запускать

```bash
npm run check
npm test
```

Проверки не требуют API-ключа и не обращаются к Bitrix24.

`server.original.js` намеренно не включён в `npm start`: он сохранён для чтения и зависит от модулей Altech, исключённых из комплекта как не относящиеся к MVP.

## Интерфейс

- `public/index.html` — полная связанная разметка рабочего интерфейса Altech;
- `public/styles.css` — дизайн-токены, стеклянные панели, воронка, модальные окна и адаптив;
- `public/app.js` — управление фильтрами, запросами, визуализацией и детализацией;
- `design/glass-reference.html` — автономный визуальный прототип;
- `design/GLASS_DASHBOARD_HANDOFF.md` — спецификация визуального языка.

Интерфейс содержит блоки вне 3ДБИЛД, потому что HTML, CSS и JS тесно связаны. Точный список сохраняемых и удаляемых паттернов находится в корневом `CODE_REUSE_MAP.md`.
