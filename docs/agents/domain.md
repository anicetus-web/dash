# Domain docs

Раскладка: **single-context**.

- `CONTEXT.md` в корне репозитория — глоссарий предметной области и ключевые инварианты расчёта.
- `docs/adr/` — architecture decision records, по одному файлу на решение.

## Правила для потребителей

- Перед работой с расчётным модулем или воронками прочитать `CONTEXT.md` — термины
  («Компания», «Потребность», «Сделка», «Когорта», «Статика», «Динамика», «КЭВ»)
  имеют строгие значения из спеки и не взаимозаменяемы.
- Тикеты и код используют вокабуляр глоссария. «Лид», «клиент», «заявка» — не наши термины.
- Перед изменением архитектурного решения проверить `docs/adr/` — возможно, оно уже принято
  и у него есть зафиксированная причина.
