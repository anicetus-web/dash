# Triage labels

Пять канонических ролей, строка метки совпадает с именем роли:

| Роль | Метка | Значение |
|---|---|---|
| needs-triage | `needs-triage` | Не разобран |
| needs-info | `needs-info` | Нужны данные извне (например, ID стадий Битрикса) |
| ready-for-agent | `ready-for-agent` | Готов к взятию агентом |
| ready-for-human | `ready-for-human` | Требует решения человека |
| wontfix | `wontfix` | Не делаем |

Записывается строкой `Status:` вверху файла тикета.
